## 1.0.12 域名、TLS 与动态地址实现（2026-10-05）

- 两款版本已改为 `1.0.12`／`112`，默认服务及手机／TV HTTPS 深链使用 `xq.suxinwl.com:8600`。本站公开 CA 仅重命名为 `site_ca.pem`，PEM 文件 SHA256 仍为 `c3e45f34739e9a56f873fdb055932f673f4de7df07e1732b53a40d4e56ff6bd9`，没有改动证书字节。
- API 24 及以上保留标准 OkHttp 和系统域名信任管理器，避免自制管理器缺少 Android 主机名验证扩展所引发的兼容异常；API 23 使用系统加本站 CA，并先执行 OkHttp 默认主机名校验，外部主机额外要求系统信任。空链、过期链和未受信链必须失败，缺少 CA 资源不得静默回退。
- 系统公信证书路径不依赖内置私有 CA 仍有效。API 23 仅在系统验证失败、尝试私有 CA 回退时验证内置 CA 有效期；新增过期私有 CA 不阻断系统信任／私有回退必须拒绝的两项回归源码。JSON 的附加证书字段不被读取或授予任何信任。
- 动态入口后台匿名获取约定 JSON，密码及 URL 可由构建环境提供；只允许同一 HTTPS 入口主机与端口的跳转。新地址通过匿名服务接口检查后保存，下次冷启动生效，并显示中文重启提示。空文件、HTML、无效协议或网络失败保留当前已验证地址；初次安装回退新域名。
- API 凭据、持久账号会话、公共目录、观看进度和下载按服务 origin 隔离。播放器、直播、下载及更新使用逐请求选择 TLS 的 Call.Factory，未来显式切换会取消原请求并清理在途目录／详情缓存。

## 构建与复验

固定环境：JDK 17、Gradle 9.1.0、AGP 9.0.1、SDK 36、Build Tools 36.0.0。依赖版本集中在 `gradle/libs.versions.toml`，各模块的 Gradle 锁文件随源码交付；API 23 所需 Java 库功能启用核心库脱糖。

```powershell
cd android
.\gradlew.bat testDebugUnitTest :app-mobile:lintRelease :app-tv:lintRelease
.\gradlew.bat :app-mobile:assembleRelease :app-tv:assembleRelease
.\gradlew.bat :app-mobile:assembleDebugAndroidTest :app-tv:assembleDebugAndroidTest
# 连接真实设备后，按设备分别执行：
.\gradlew.bat :app-mobile:connectedDebugAndroidTest
.\gradlew.bat :app-tv:connectedDebugAndroidTest
```

发行构建需要 `XIAOQI_SIGN_STORE`、`XIAOQI_SIGN_STORE_PASSWORD`、`XIAOQI_SIGN_ALIAS`、`XIAOQI_SIGN_KEY_PASSWORD`。签名证书 SHA256：`c0a3c9ff3a9dc1b3966b67051ae557a3a84a868ef0b582c61a563a77c74dde78`。

本机签名密钥单独保存于 `E:\AndroidDev\private`，不包含在源码、插件和开发环境压缩包中。迁移前须由维护者单独备份；后续发行继续使用相同密钥。

在 Go 根目录可执行 `go run ./plugins/suxinvideo/tools/publish_android --version 1.0.10 --code 110` 发布已构建 APK，或使用后台客户端发布页管理后续版本。公开发布元数据在 `android/releases.json`；下载入口为 `/suxinvideo/app-download`。1.0.10 两包沿用原发行签名，已安装 1.0.9 或更早版本的设备需升级 APP；覆盖安装及保留账号、本地记录仍待真机验证。

Android 源码包由 `python android/package-source.py` 生成，排除 SDK、构建缓存、私钥和本机路径配置。完整开发包由 `python package-go-development.py` 生成，包含 Go 与 Android 源码、两个公开 APK 和 `suxinvideo.zip`，不包含 PHP 项目。
