# 123 云盘文件上传

## 本机运行

- 后台：<http://127.0.0.1:8601/webadmin/#/datacenter/configuration>，点击“文件上传配置”。
- 独立数据库：`goframepro_pan123`。Ebook 的 8600 服务与数据库未修改。
- 本机管理员账号信息：`runtime/local-admin.txt`（不进入版本控制）。
- 前端源码：`web`；部署文件：`resource/webadmin`。
- 停止当前本项目进程后，可在项目根目录执行 `go run main.go` 启动。
- 前端重新构建：在 `web` 执行 `npm ci`、`npm run build`，将 `dist` 内容复制到 `resource/webadmin`。

## 配置步骤

1. 选择“123 云盘”，填写开放平台的 clientID、clientSecret 和目标目录 ID。
2. 先在 123 控制台启用该目录的直链；URL 鉴权开关与控制台保持一致，开启时填写 CDN 鉴权密钥。
3. 点击“测试连接与上传”。工具上传小图片和 PDF，校验内容、直链及过期签名，再将测试文件移入云盘回收站；界面逐项显示结果。
4. 测试通过后保存。切换存储仅影响新上传，旧文件保持原地址。

密钥读取接口只返回已配置标志，输入框留空保留原值。配置保存会验证账号身份；有旧 123 附件时禁止换成其他 UID。同一账号可以更新密钥或目标目录。鉴权开关不会改变本站公开附件的访问策略，也不会修改 123 控制台。

数据保存在 `manifest/config/upload.yaml` 的 `pan123` 节点，凭证缓存保存在非公开的 `runtime/pan123`。生产配置、缓存及本机账号信息不可发布到前端或代码仓库。

## 接口与数据

- 原有配置接口扩展 `Type=pan123`；表单新增 `clientID`、`clientSecret`、`parentId`、`urlAuth`、`cdnKey`。
- `POST /admin/datacenter/uploadconfig/testConnection`：使用当前表单测试，返回 `success`、`uid`、`steps`；受登录与 `pan123Test` RBAC 权限控制。
- `GET/HEAD /common/storage/pan123/{uid}/{fileID}/{name}`：核对附件记录后生成直链重定向，响应 `Cache-Control: no-store, private`。
- 附件保存稳定相对路径，`location=pan123`。已有配置或默认存储切换不会将云盘地址拼到其他云厂商域名下。
- 云盘删除调用回收站接口。删除失败保留记录；递归删除部分完成时保留失败节点及父目录，允许重试。
- 文件大小使用 `BIGINT UNSIGNED`；实际限制仍取系统配置与 123 单文件 10GB 上限中较小者。

旧安装升级执行 `manifest/sql/pan123.sql`（默认 `gf_` 表前缀），同步代码与前端后重启。新安装 SQL 和安装包中的三个前端功能文件已同步包含本功能。
