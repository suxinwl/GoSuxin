# 来源与许可记录

GoSuxin V1.0.0 基于独立维护的分支。核心、CLI 与六个 SQL 驱动来源为 GoFrame 2.9.8；Redis 适配器为 2.9.3。准确模块映射见 modules.json。源代码来自 Go 模块缓存中对应版本的公开发行源码。

上游仓库：https://github.com/gogf/gf 。framework/LICENSE 及各子模块 LICENSE 保留 MIT 原文和版权主体；原文件头部的必要作者声明保留。第三方依赖与内嵌 JavaScript 的许可证保持原样，不改为 Suxin 所有。应用与前端的新增或自主维护内容由 Suxin技术团队维护。

更改范围：模块路径、版本、产品标识、CLI 离线初始化和在线入口策略、模板及生成器、业务后台及存储扩展。字符串算法测试中的上游品牌字符串属于测试数据，保留以维护长度、位置、编码断言；不是产品展示。兼容环境变量 GF_* 和部分内部包名不对外表示上游依赖。

文档来源见 ../site-migration/sources.json。未确认原站文档许可，因此采用原创说明，不复制整站正文与原站图片。文档导航主题保留来源映射以便复核。
