# GoSuxin 2026-10-09 变更说明

以 GoSuxin 主线整合 GoframePro 2.9.7 的后台增强、四个业务插件及 Android 开发源码，并完成运行插件安装协议。框架 Go 模块、CLI 和应用显示版本仍为 1.0.0；本次发行标签为 `v1.0.0-runtime.20261009`。

## 主程序与安全

- 合入后台左侧、顶部和双列布局，以及卡片、间隔卡片、半圆角和圆角页签；旧设置补齐字段并持久保存。
- 修复首次安装的数据库配置、管理员账号处理及登录锁定；保留已有数据库与表前缀。
- 将业务 `storage` 忽略规则限定到根目录，确保画册存储设置前端页面随源码提交。
- JWT 仅接受 HS256；补齐仅解析场景的签名校验、短令牌检查和动态令牌校验。
- 操作日志过滤 Authorization、Cookie、apiverify 和插件内部密钥/身份头，保留原始请求行为。
- 修复 HTTP 流式代理和已发送响应的处理，保留文件正文、状态码、Range、Cookie 和影视 APP 的成员令牌。

| 插件 | 版本 | 本次交付 |
| --- | --- | --- |
| 电子画册 `ebook` | 1.0.0 | 分类、图片/PDF 画册、阅读器、分享、访问记录、站点及存储设置 |

| 私有插件仓 `privatecode` | 1.1.5 | 分类、资料、源码/运行包归档、不可覆盖历史版本、哈希核验及权限内下载 |
| 统计分析 `analysis` | 1.0.0 | 实际日志和业务数据统计、时间趋势、模块及终端分布、按角色限制统计范围 |

迁入仅使用表结构、菜单、分类及默认配置；不导入旧影片、订单、画册、上传文件或账号密钥。自动采集和直播后台任务默认关闭。私有插件仓保留历史源码及小柒影视 APP 条目，并新增四个运行包条目，每个条目提供 Windows/Linux x64 版本。

小柒影视 Android 手机/平板与 TV 源码为 1.0.16（versionCode 116），位于 `apk/videoapk/android`，包含 Gradle Wrapper、模块、锁文件、测试和公开 CA 证书。签名密钥、签名密码、设备截图及本机构建产物不发布；本次没有重新构建或签发 APK。

## 运行插件：安装期间宿主持续运行

- 新增 `suxin-runtime-v1` 格式、独立插件进程 SDK、宿主管理器和四个插件入口。
- 服务器直接安装预编译 ZIP，不需要 Go、Node.js，也不重新构建宿主二进制。
- 四个已内置插件可切换到独立运行包，沿用原 API、菜单权限、阅读器和影视 APP 地址。
- 校验系统/CPU、路径、文件 SHA-256 和协议；健康检查成功后生效，启动失败回退旧版本。
- 管理请求先由宿主执行登录和 RBAC 校验，再经本机随机密钥通道转交；客户端伪造的身份头不会传入插件。
- 更新、卸载及重装保留业务表、文件、配置、菜单 ID 和角色授权；重启宿主恢复已保存状态。
- 修复菜单打开独立管理前端时的跳转和嵌套，保留已有菜单自定义项。

首次启用新协议需要一次宿主升级及后台静态文件更新。后续插件操作不启停宿主；更新会替换插件进程，该插件的上传、播放或后台长任务可能中断。

## 包与源码

GitHub Release 提供 8 个运行 ZIP（4 插件 × Windows/Linux x64）、4 个对应插件源码 ZIP、完整主线源码 ZIP、Android 1.0.16 源码 ZIP、两个平台的宿主部署 ZIP，以及 `packages.json`、`SHA256SUMS.txt`。

运行包用于后台安装；插件源码包用于开发，需与同一提交的完整 GoSuxin 源码配合编译。影视源码以主线实际调用的 `api`、`internal`、`web` 和 `third_party` 为准，不使用历史 `plugins/suxinvideo/go`、`vue` 镜像作为编译来源。所有源码包记录提交 SHA 和逐文件哈希。公开发行不包含本机数据库密码、云盘密钥、私有插件仓业务记录、运行状态、缓存或上传文件。

构建和发布准备工具：

```bash
python scripts/build-runtime-plugins.py --os windows --build-web --build-host
python scripts/build-runtime-plugins.py --os linux --build-host
python scripts/prepare-github-release.py --commit HEAD --tag v1.0.0-runtime.20261009
```

Windows/Linux 包由开发机构建，服务器仅执行预编译程序。PDF 转换另需 Poppler，Linux 影视转码另需系统 FFmpeg。宿主部署包按指南保留原配置、数据库、业务文件及插件状态，不能覆盖现有数据库重新安装。
