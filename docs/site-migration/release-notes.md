# GoSuxin V1.0.0

首个独立维护版本，提供业务后台、框架、Suxin CLI、六种 SQL 驱动、Redis 和 SDK HTTP 客户端源码。统一正式模块路径与版本，CLI 使用内置模板并暂停原厂在线升级。

后台包含 123 云盘上传及稳定附件访问、品牌与默认头像统一、首页演示数据清理、在线服务筹备提示。提供安全初始化 SQL、版本元数据迁移与示例配置。

文档资料包含 34 篇主题章节、原项目 21 个目录节点映射、7 篇 CLI 文档、快速开始目录与 9 篇教程；官网尚未部署。前端构建通过，既有类型检查问题及未执行项详见 validation.md。

安装前阅读仓库 README。Windows CLI 下载后可重命名为 suxin.exe 加入 PATH。源码首次运行先执行 python scripts/init-local-config.py 创建本机配置，再填写独立数据库。不要用初始化 SQL 覆盖已有数据库。
