# 国际化、主题与品牌

适用：Suxin Framework V1.0.0 / Suxin CLI V1.0.0。

前端多语言由 web/src/locale 及页面 locale 文件组织。新增文案采用稳定键名，并补齐受支持语言；不要把密钥或运行目录放进翻译内容。后端国际化资源按 manifest/i18n 及框架配置加载，接口错误使用项目既有约定。

品牌显示为 GoSuxin开发框架、Suxin技术团队、深圳市速信网络科技有限公司。官网 https://www.suxinwl.com，默认邮箱 56308750@qq.com，地址中国·深圳；旧默认备案号和电话清空。自定义联系方式保持不变。

图标来自品牌资料的原始资源，resource/static/brand/logo.png 用于独立默认头像；web/public 保存浏览器入口图标。头像不经上传存储配置解析，因此切换云存储不会破坏默认头像。自定义头像保留。
