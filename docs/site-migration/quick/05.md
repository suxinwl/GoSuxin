# 使用规范路由

适用：Suxin Framework V1.0.0 / Suxin CLI V1.0.0。

规范路由的请求类型嵌入 g.Meta，例如：
```go
type GreetReq struct {
 g.Meta `path:"/greet" method:"get" summary:"问候" tags:"示例"`
 Name string `json:"name" v:"required"`
}
type GreetRes struct { Message string `json:"message"` }
type Controller struct{}
func (c *Controller) Greet(ctx context.Context, req *GreetReq) (*GreetRes, error) {
 return &GreetRes{Message: "你好，"+req.Name}, nil
}
```
以上片段需要导入 context 和 frame/g。服务器通过分组 group.Bind(new(Controller)) 绑定。下一节介绍组中间件；返回对象要配合统一响应中间件输出 JSON。
