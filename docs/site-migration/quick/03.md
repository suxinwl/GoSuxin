# 获取请求参数

适用：Suxin Framework V1.0.0 / Suxin CLI V1.0.0。

在上节处理器中使用 name := r.Get("name", "访客").String()，然后 r.Response.Write("你好，" + name)。访问 /hello?name=Suxin 核对返回值。Get 返回可转换的值对象；默认值解决缺省参数，不等同于验证。

数字使用 Int 等转换方法前，仍需验证允许范围。不要把未经校验的字符串直接拼入 SQL、文件路径或重定向地址。多来源参数应使用清晰的 API 定义，避免同名 Query 与 Body 的歧义。
