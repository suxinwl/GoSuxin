# Hello World

适用：Suxin Framework V1.0.0 / Suxin CLI V1.0.0。

将独立示例 main.go 写为：
```go
package main
import (
 "github.com/suxinwl/GoSuxin/framework/frame/g"
 "github.com/suxinwl/GoSuxin/framework/net/ghttp"
)
func main() {
 s := g.Server()
 s.SetPort(8612)
 s.BindHandler("GET:/hello", func(r *ghttp.Request) {
  r.Response.Write("Hello Suxin")
 })
 s.Run()
}
```
执行 go run .，访问 http://127.0.0.1:8612/hello，应返回 Hello Suxin。GET 是方法约束，/hello 是路由路径。修改端口应重启程序。
