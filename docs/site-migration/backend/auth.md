# 请求校验、登录、RBAC 与跨域

适用：Suxin Framework V1.0.0 / Suxin CLI V1.0.0。

请求先经过项目协议校验，然后登录态与角色权限检查。后台前端请求封装负责 API 校验头和响应解包；apisecret 是项目协议配置，不能代替用户认证。用户凭证由 utility/auth 管理，业务代码从请求上下文取得用户身份。

路由中的 noValApi、noLogin、noAuth 是特殊豁免标记，使用前应明确接口是否公开。新增后台接口默认沿用后台中间件，权限表记录与路由匹配。前端按钮权限仅用于交互，后端必须再次检查。

跨域由 app.allowurl 及路由中间件处理，部署时填写实际前端来源。排错顺序：网络状态、协议校验、登录失效、角色授权、业务错误。不要用通配跨域加关闭鉴权来掩盖配置错误。登录密钥、数据库口令和存储密钥只放本机配置。
