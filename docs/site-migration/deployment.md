# 部署、升级与排错

适用：Suxin Framework V1.0.0 / Suxin CLI V1.0.0。

部署前执行 Go 测试与编译、前端构建、文档与版本检查，保留验证结果。发布代码包含示例配置；真实数据库和云盘凭证由部署者填写。不要用示例配置覆盖现有生产配置。

编译后的程序从项目目录运行，反向代理转发 API 和静态资源。当前本机后台使用 8601；其他环境按 server.address 调整。更新前备份程序、静态文件、配置和数据库，确认停止的进程确实属于当前项目，再启动新程序并检查登录、权限、头像和附件。

排错：端口占用时检查监听进程；模块下载失败时检查标签及模块代理，不能用本地工作区通过来替代正式安装验证；页面白屏时检查构建 base 与静态资源 HTTP 状态；云盘失败查看 HTTP 状态、业务代码和追踪号，勿在日志输出密钥。

其他数据库驱动编译验证与真实连接验证分开记录。前端既有类型问题和未覆盖的业务场景见 validation.md，不把未执行项标为通过。
