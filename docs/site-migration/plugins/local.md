# 本地插件开发、打包与安装

适用：Suxin Framework V1.0.0 / Suxin CLI V1.0.0。

插件以现有业务目录规范组织 API、控制器、逻辑、前端页面、数据表和菜单权限。开发前确认名称不与已安装模块冲突，版本独立于框架版本；第三方插件保留自己的版本与许可证。

本地打包页面填写名称、标识、版本和说明，选择实际需要的后端文件、前端目录、数据表与菜单。打包前检查配置、SQL 和资源，剔除账号、密码、日志及业务记录。Service、DAO 等可生成代码按项目打包逻辑处理，安装后核对生成步骤。

本地安装会修改项目文件或数据库，先备份并在测试项目验证。安装后检查路由绑定、权限记录、菜单、前端构建和回滚方式。在线上传市场、购买和自动绑定目前筹备中，不使用原厂在线入口。

原项目的“插件开发规范”章节为空，本章依据 internal/logic/admin_developer 与本地打包页面补写，不宣称原站存在完整规范。
