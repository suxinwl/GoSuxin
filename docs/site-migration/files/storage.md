# 文件存储与附件访问

适用：Suxin Framework V1.0.0 / Suxin CLI V1.0.0。

文件上传配置位于数据中心 → 数据管理 → 文件上传配置，支持本地、原有对象存储及 123 云盘。修改默认类型只影响新上传；附件记录保存 location，以对应适配器处理历史文件。

上传先检查扩展名及大小，摘要按完整文件内容计算并按存储位置去重。业务页面通过统一 URL 辅助函数访问附件，避免复用其他存储里的同名文件。公开附件延续当前项目的访问方式，不能把随机路径当作用户授权体系。

删除需要处理远端存储结果：失败时返回错误并保留记录，文件夹递归删除也采用同一逻辑。清理历史数据前先确认附件未被业务引用。默认头像使用独立静态资源，不写入附件上传目录。
