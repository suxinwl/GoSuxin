# 小柒影视电视直播

## 使用入口

- 网页：`/suxinvideo/live`，四套主题的“直播”导航。
- 手机／平板：APP 首页直播入口、频道页的“影视／直播”切换。
- TV：直播导航，方向键选择频道和线路；确认键播放，返回键退出全屏或返回频道列表。
- 后台：速信影视CMS后台 → 直播管理（`content/live`）。

直播免费向游客开放。节目单、回看、录制和直播投屏尚未提供。

## 港澳台与 CCTV 分组

2.4.9 起，“港澳台”排在业务分组第一、“CCTV”排第二；网页和 APP 保留“全部／全部频道”快捷筛选。港澳台按稳定频道标识及公开地区元数据归类，包含香港、澳门、台湾频道，翡翠台、凤凰中文台、凤凰资讯台、凤凰香港台依次置顶；CCTV 按台号排序。

升级沿用原有频道和线路编号，只调整自动维护频道的分组与排序。系统分组使用独立稳定标识，重复启动、升级及订阅刷新不会重建同名分组；管理员手动编辑的名称、分组、排序和启停优先保留。旧分组及失效线路保留，公开列表仅展示有启用频道的分组。

四套网页主题、Android 手机／平板和 TV 共用同一接口顺序。Android 1.0.10（110）进入直播后点击刷新或重新进入页面即可获取调整，无需更新安装包。播放侧栏优先显示正在观看的频道，其余保留服务端顺序。

## 后台管理

频道、分组、线路和订阅分为四个管理标签。先预览导入结果，再提交后台任务；任务进度可在刷新页面后恢复。导入支持 M3U、`频道名,地址` TXT 及手动 HTTP／HTTPS HLS 地址；RTMP、RTSP、UDP 等协议会提示不支持。

频道优先按 `tvg-id` 识别，同频道归并为多个线路；`@HD`、`@SD` 是线路版本。无标识时按规范化名称及管理员别名匹配。翡翠台与黄金翡翠台为独立频道。管理员修改的名称、排序、启停及请求头不会被订阅刷新覆盖。

首次安装创建 IPTV-org 的中国大陆、香港、澳门和台湾订阅，每六小时刷新。下载失败保留上次成功数据；新增线路经过检测后可播放，失败线路标记不可用并保留供重试。实际可用性由上游、地区及本机网络决定，目录中存在频道不代表其全部线路可播放。

当内置生成目录不能访问时，程序仅对这四条固定订阅尝试同一官方仓库备用目录。自定义订阅不使用该备用机制。

播放默认使用最近成功或健康且优先级较高的线路，失败先刷新当前线路一次，再顺序尝试同频道备用线路。管理员可选择线路进行预览或重新检测。

## 接口与媒体

| 接口 | 用途 |
| --- | --- |
| `GET /suxinvideo/app/v1/live/groups` | 分组 |
| `GET /suxinvideo/app/v1/live/channels` | 分组、搜索、分页；`channel_id` 获取单频道 |
| `POST /suxinvideo/app/v1/live/resolve` | 选择频道及线路，获取独立媒体会话 |
| `POST /suxinvideo/app/v1/live/renew` | 延长会话，保持既有媒体 URL 身份 |
| `GET /suxinvideo/live/media` | 不透明会话资源地址，动态清单与媒体代理 |
| `/admin/suxinvideo/live/*` | 按操作校验宿主权限的后台接口 |

公开接口不暴露上游地址和源请求头。会话两小时有效，客户端自动续期；服务器每次请求检查频道、分组及线路启用状态。源 URL 修改后需重新解析。HLS 动态清单不缓存，保留媒体序列、滑动窗口、密钥及 discontinuity 标记，不经过点播广告过滤或红果转码。

后台返回时恢复到直播位置；控制栏显示“直播中”，无需显示影片总时长。最近观看频道与电影观看历史分开保存，不生成影片进度、下一集或离线下载。

## AVC 备用恢复

开发环境已对官方仓库中的央视及主要卫视候选逐一验证清单、片段和实际 H.264 解码。`docs/live_avc_seed.m3u` 包含本次确认的公开 AVC 备用，不含帐号、签名、Cookie 或请求头密钥。公开直播地址可随上游调整；恢复时仍须重新检测，文件中的记录不直接标记为健康。

迁移开发环境时备份并恢复完整业务数据库，已有直播频道和人工配置随数据库保留。全新数据库或需补齐这些备用时，在 Go 宿主目录运行：

```powershell
go run ./plugins/suxinvideo/tools/live_seed -file ./plugins/suxinvideo/docs/live_avc_seed.m3u -group "中国大陆"
```

本机工具复用 CMS 的 URL 安全检查、频道合并和媒体检测，并将结果记录为 `local_seed` 任务。重复执行不创建相同线路；既有分组、人工名称、排序、启停、请求头和优先级保持原值。通过检测且未由管理员设置的 AVC 备用优先级设为 100，失效线路保留。具备 HEVC 解码能力的原生 APP 可手选原 HEVC 源，网页所用 HLS 引擎可能不支持 HEVC MPEG-TS。

## 自托管动态来源、授权与节目单

Go 宿主在原频道与线路表上保存稳定的来源实例、模块及频道引用。动态媒体地址只在解析时生成，不作为频道标识持久化。公共实例使用本机 9180，会员实例使用本机 9181；网页、APP 和分发清单返回主站的不透明媒体会话地址。HLS、FLV 和有限事件回放均沿用主站媒体权限检查。

后台“直播 → 来源与接入”提供模块配置、管理员账号登录、逐会员逐模块授权、分发配置、订阅地址、频道绑定预览及节目单。公共模块保持上游电视模块的默认启用状态，手动来源与赛事模块默认关闭；已有数据库的启停选择保持。会员实例全部线路要求管理员显式配置会员编号白名单，站点 VIP 不隐含任何来源授权。

新增六表为 `sx_live_module`、`sx_live_profile`、`sx_live_member_access`、`sx_live_distribution`、`sx_live_programme`、`sx_live_provider_binding`，插件安装合计 48 表。升级补列保留现有频道、线路编号及人工控制。订阅令牌绑定会员与分发配置，生成后仅显示一次；重新生成、撤销、会员停用或移除模块授权会使既有媒体会话失效。

APP 节目单接口为 `GET /suxinvideo/app/v1/live/epg?channel_id=…&date=YYYY-MM-DD`，起止时间使用 Unix 秒并声明 `Asia/Shanghai`。无节目时返回空列表，不生成占位节目。电视回看只在实际来源具备该能力且节目已结束时开放；赛事回放使用上游返回的独立回放引用，不拼接电视时间窗。解析通过 `POST /suxinvideo/app/v1/live/replay/resolve`，后续媒体与续期保持同一节目身份和授权。

M3U、TXT 与 XMLTV 分发路径分别为 `/suxinvideo/live/subscription/{token}/index.m3u`、`index.txt`、`epg.xml`。每次清单、节目单、解析、续期和媒体访问均检查同一会员及模块权限；清单不包含引擎本机地址或上游账号凭据。

迁移时同时备份业务数据库、`data/suxinvideo/iptv-engine/internal.secret` 和各实例数据目录。模块配置使用从此独立密钥派生的 AES-GCM 密钥加密；缺失或替换密钥将无法解密已有配置，修改站点代理签名设置不会改变此密钥。备份需与普通公开源码及发布包分开保存。
