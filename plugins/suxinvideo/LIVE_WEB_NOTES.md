# 网页直播播放器

四套前台主题共用 `live_site.go`、`live_web.js`、`live_web.css`，入口为 `/suxinvideo/live`。资源缓存版本为 `1.0.9.1`。

## 手机布局与操作

- 画面内保留单行播放、声音、直播状态和全屏控件。线路和清晰度显示在画面下方；进入全屏后通过“线路”打开设置面板，退出全屏时还原位置。
- 频道名称最多显示两行，完整名称保留于无障碍名称和标题。台标加载或失效时显示文字占位；分组横向滑动，频道列表可独立上下滚动。
- 页面使用服务端提供的中文频道、分组和线路名称；不在网页维护另一套后台名称映射。
- 显示控件的移动事件只处理鼠标指针，避免触屏兼容鼠标事件与点按相互抵消。
- 手机禁止有声自动播放时尝试静音播放，并提供“开启声音”；仍被禁止时显示点击播放。加载有提示，失败可以重新连接或选择频道。
- Apple 浏览器优先使用原生 HLS；其他支持 MediaSource 的浏览器使用 HLS.js。媒体分片等待 35 秒，连续停滞 40 秒才恢复线路。切换频道取消旧请求。

## 检查

结构检查：`go test ./internal/controller/suxinvideo -run TestLivePagesUseIndependentPlayerInAllThemes`。

浏览器行为检查：安装 Python Playwright 与 Chromium 后，在宿主根目录执行 `python plugins/suxinvideo/tools/test_live_web.py`。脚本生成四主题测试页面，模拟接口和媒体，检查自动播放限制、逐条换线、清晰度、全屏设置面板及退出还原。此脚本不能替代真实频道播放验收。

真实验收必须使用实际 `/suxinvideo/live` 和媒体接口，不拦截页面、清单或分片；分别记录手机浏览器模拟环境和真机结果。Android 原生 APP 使用自己的播放器，不能用网页通过结果代替 APP 验收。
