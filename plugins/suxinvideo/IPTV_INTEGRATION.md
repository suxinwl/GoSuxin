# 小柒直播引擎 2.5.0

## 架构及运行

Go 服务继续运行于 HTTPS `:8600`。它管理两个固定的 Node 24 内网实例：公开来源 `127.0.0.1:9180`，账号来源 `127.0.0.1:9181`。账号实例在后台启用账号模块后启动。两实例分别使用 `data/suxinvideo/iptv-engine/public`、`member`，不会共用账号、缓存或浏览器登录状态。

执行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\start-suxinvideo-latest.ps1` 构建并启动最新版。首次启动安装锁定的 Node 依赖；浏览器、Node 24 和 FFmpeg 部署见 `third_party/akiralereal-iptv/adapter/install-windows.ps1` / `install-ubuntu.sh`。可用 `SUXIN_NODE`、`SUXIN_FFMPEG`、`PUPPETEER_EXECUTABLE_PATH` 指定现有工具。

Go 负责健康检测、退避重启、Windows Job Object／Linux 进程组回收。Ubuntu systemd 服务托管 Go，`KillMode=control-group` 回收全部子进程。运行密钥、账号和浏览器配置仅在独立数据目录；迁移时单独、安全地备份该目录，不放入源码包。

## 后台

进入直播管理的“来源与接入”，管理免登录电视模块、赛事／直播间模块、账号登录、会员白名单、频道映射、节目单、配置档和订阅分发。来源刷新为后台任务，沿用现有任务进度；失败不删除已有目录。签名 URL 只在播放时解析，线路身份为实例、模块、上游频道／房间编号。

扫码登录、浏览器登录或导入登录态时，会在具有模块配置权限的前提下启用对应会员模块，并等待账号引擎管理接口启动后提交登录。管理接口已就绪但频道数为零是首次登录的正常状态；登录方式按平台能力显示，咪咕等平台通过配置字段填写登录凭据。配置重放与登录按实例串行，避免重启初始化覆盖新登录态。

公开线路游客可看。账号线路仅限对应模块白名单中的本站会员，VIP 本身不会授予平台账号线路。账号、模块、会员、登录令牌、分发令牌停用或重置后，后续媒体请求重新校验。后台敏感配置脱敏，留空保留原值，数据库中的管理员凭据使用加密存储。Node 原生登录状态仍由独立私有文件或浏览器 profile 持久化。

港澳台第一、CCTV 第二，翡翠和凤凰系列置顶。翡翠与黄金翡翠、不同地区版本保留独立频道。后台映射预览用于处理不明确的频道匹配，不导入上游公告短片。

## 媒体、节目单和回看

客户端仅收到本站授权媒体地址。原生 HLS 保留动态窗口、清晰度、AES-128 密钥和序列；HTTP-FLV 使用独立 FFmpeg 实时滑动 HLS，默认最多两个共享媒体桥，最后请求超过 60 秒释放。桥优先转封装，不使用红果点播引擎。赛事 MP4 使用有限播放与 Range。

节目时间存 UTC，网页和 APP 按北京时间展示。节目单存在不代表回看可用：只有实际声明并验证的平台回看线路、且节目已结束，才提供回看入口。没有节目单显示“暂无节目单”。未增加本站 DVR 录制、六合彩录像或虚构回放。

分发令牌绑定本站会员和配置档，生成 `index.m3u`、`index.txt`、`epg.xml`，可撤销／重置；媒体继续检查相同权限。完整接口见插件 OpenAPI 与 Node `ADAPTER.md`。

## 升级、源码和回退

数据库升级幂等，保留原频道、线路、手动配置和其他 CMS 业务数据；卸载保留业务表及私有运行目录，并停止插件管理的子进程。Node 源码、GPL 许可、哈希清单、锁文件、部署脚本在插件及开发包内；不含 `node_modules`、登录资料、缓存或 APK 签名密钥。

APK 1.0.11／111 沿用已有签名。网页节目单共用组件适配四套主题，手机、平板、TV 原生界面独立于点播记录与下载。

停用引擎回退：执行启动脚本并添加 `-DisableIptv`，保留原 Go HLS 线路。升级前的插件、Go 可执行文件及私有直播数据快照在 `data/tmp/iptv-pre-250-*`；不随交付包分发。不要通过旧版本覆盖数据库或删除新表来回退。
