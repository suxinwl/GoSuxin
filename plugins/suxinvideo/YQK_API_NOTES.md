# 小柒片源接入（一起看 APP接口）

## 2.3.22 多源片库与内容屏蔽

小柒八个频道默认使用本站已采集的多源影片，保留篮球、足球、动漫等原有子分类。小柒远端专题通过 `source=remote` 独立访问。

全局内容屏蔽在采集、自动补源、前台展示与直接播放时生效；远端分类编号不与 `sx_type` 混用。命中影片保留在数据库，前台不展示，直接访问返回未找到。规则位于后台“系统设置 → 内容屏蔽”。

小柒是一个聚合采集源，同一影片的多条播放线路来自 APP 详情，不是多个独立的采集接口。接入代码包含本地 `yqk/signing/go` 的 Go SDK，安装包和开发包均包含对应源码，无需另外运行 Python 签名服务。

## 配置入口

- 后台“采集管理”中使用“小柒 APP”，接口地址为 `yqk://app`。
- “系统设置 → 站点信息”的“小柒动态入口（JSON）”保存服务器生成的入口索引地址，配置键为 `yqk_bootstrap_url`。
- 默认索引是[服务器入口 JSON](https://59.36.165.33:8976/down/l7e07KwFjWE7.json)。它返回配置文件 URL 列表，配置文件提供 API 后端；APP 初始化还会返回更新后的配置域名。
- 无需将短期 API 域名、抓包签名或某一集的 m3u8 地址填入采集源。
- 新增采集源默认不自动定时采集；可在后台启用自动采集，或使用预览、分类筛选与手动采集。停用小柒源后，已有影片中的小柒线路也会隐藏。
- 小柒使用游标分页，应从第 1 页连续采集；游标保存 6 小时，失效后页面会提示重新开始。定时任务采最新列表的第一页，上游接口没有可验证的小时范围筛选，不能保证精确按最近若干小时增量采集。

## 接口与播放

| 接口 | 用途 |
| --- | --- |
| `/v2/api/home/header` | 首页导航频道 |
| `/v2/api/home/firstScreen` | 首页推荐影片 |
| `/v1/api/vodRank/getRankList` | 上游热播榜 |
| `/v2/api/channel/topicListView` | 频道专题及精选片单 |
| `/v1/api/vodTopic/getVodList` | 真实专题内容分页 |
| `/v1/api/search/search` | 关键词搜索与搜索游标 |
| `/v1/api/search/queryNow` | 全站影片列表游标及最近、热度排序 |
| `/v2/api/vodInfo/index` | 影片元数据与各线路分集 |
| `/v2/api/vodInfo/epDetail` | 分集支持的实际清晰度，参数 `vodEpId` |
| `/v2/api/vodInfo/playUrl` | 按 `epId`、`vodResolution` 解析播放地址 |

每次请求生成新的请求编号和签名，匿名设备标识在当前开发环境保存。网络故障触发后端切换和入口刷新；业务错误不会无休止重试。请求使用 HTTPS，禁止访问私网及重定向到不安全目标。

影片合并保留现有片源，核对片名、年份、地区和类型，避免同名重拍合并。小柒线路使用 `yqk_<vodPlayerKind>` 代码，与直接采集的资源站保留独立来源。同线路同集更新替换原地址，不追加重复集数。小柒适配器排除名称含豆瓣、黄豆、黄果的线路；其它已配置采集源沿用管理员自己的启停设置。

数据库保存稳定分集引用 `yqk://<vodId>/<vodPlayerKind>/<epId>`。播放页在校验当前线路、会员与积分权限后，实时解析媒体并显示源站提供的清晰度；媒体、HLS 分片和密钥经过现有的限时签名代理。不会将抓包中短期播放 URL 作为永久地址保存。

## 2.3.20 频道导航与首页片单

三套主题的桌面导航及手机侧栏默认显示小柒发布的八个频道：短剧、奈飞Netflix、电影、电视剧、动漫、综艺、高清韩剧、体育。频道使用 `/suxinvideo/channel?id=<channelId>`，远端频道编号与本站分类编号分别处理，保留后台分类管理。

频道页显示上游真实专题和精选片单。选择专题后按 `/v1/api/vodTopic/getVodList` 返回的页数翻页；全站“最近更新”和热度列表使用上游游标分页。频道精选集合显示源站提供的预览，不将专题预览当作完整、可任意翻页的分类库。频道内的内容以 APP 发布的专题归属为准，包含交叉分类的 Netflix、高清韩剧等栏目。

首页“最近更新”取源站最新列表，“热播”取上游榜单，顶部轮播取首页推荐影片。页面读取最近一次成功快照并在后台刷新，进入播放、用户中心或支付页面时导航加载不等待远端接口。接口失败时保留可用快照，缺少列表时回退本站影片；首次启动可能先显示本站内容，后台快照就绪后刷新页面即可看到小柒片单。

影片卡片使用限时签名的站内详情入口。点击后取得完整影片详情，匹配已有影片并合并线路，或新增当前影片，再进入本站详情页；片单中的上游编号不会直接当成本地影片编号。播放继续使用现有的会员、积分、线路启停、清晰度和自动换线逻辑。

在“系统设置 → 站点信息”可配置：

- **小柒频道导航**：默认开启，关闭后使用本站分类导航。
- **首页推荐内容**：默认“小柒最近更新与热播”，可改为“本站影片”。
- **首页顶部轮播**：默认“小柒热门影片”，可改为“幻灯管理”，优先显示已启用的顶部幻灯；SuxinPro 没有顶部幻灯时再取影片位置幻灯。

“首页幻灯片”开关仍控制轮播显示。启动升级及重复安装仅补充缺失的默认设置，保留已保存的导航、推荐和轮播选择，也保留影片、采集计划和管理员的源启停状态。

服务重启时，仍在运行且十分钟内有进度的单源手动采集会从当前页创建续采任务，完整重做当前页以免遗漏；已采影片通过幂等更新保留。原任务统计留在历史记录，新任务使用新的编号。主动停止、历史中断、禁用源不会自动恢复；小柒游标失效时会明确报错，不会静默跳回第一页。

## 运行与限制

安装或升级插件后需要重新编译 Go 服务。后台 Vue 页面也需重新构建。开发环境执行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\start-suxinvideo-latest.ps1`，启动当前源码。

请求签名针对本地项目所验证的 APP 版本。APP 升级或远端规则变化后需要同步 SDK；采集接口返回线路不等于媒体可播放，源站的失效、限流及地区限制仍会由采集与播放页面报告。自动补源沿用影片身份匹配与媒体检测，不保存未通过验证的临时直链。
