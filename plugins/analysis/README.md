# 统计分析 1.0.0

由 GoframePro 在线插件 `analysis` 1.0.0 适配至 Gosuxin。沿用浏览器、终端及模块图表布局；固定演示数值全部替换为实际数据库统计，不导入演示数据。原包只有前端模板，本版补充独立后台接口。

后台入口：`/suxinweb/analysis`。支持近 7、30、90 个自然日、每日趋势、每两小时操作量、模块排行、登录终端及地域。按主程序所在时区归集，适配 MySQL 驱动的时间存储设置。空数据按 0 展示，缺失日期自动补齐。

- 后台操作次数与不同 IP：操作日志。
- 成功登录、浏览器、终端、地域：登录成功记录。地域缺失显示“未解析地域”。
- 画册阅读：画册访问记录。
- 影视、画册、私有代码及影视会员数量：对应现存数据表。

超级角色可看全部数据。普通角色仅看本人日志、画册与私有资料，不展示全局影视数据。接口 `/admin/analysis/overview` 需要主程序登录和统计权限。不增加采集任务或修改已有业务数据。

插件市场支持即时安装、卸载，重启保留安装状态。本插件只初始化菜单权限。Release 提供 Windows/Linux x64 的 `analysis-1.0.0-<os>-amd64.zip` 运行包及对应源码包。上传运行包可更新已内置的统计功能，无需重新编译或重启宿主。

独立入口为 `plugins/analysis/cmd`；开发机运行 `python scripts/build-runtime-plugins.py --os linux --plugin analysis --build-web` 生成运行包。源码包供开发使用，不能作为服务器运行包安装。安装、回退及权限协议见 [运行插件指南](../../docs/runtime-plugins.md)。
