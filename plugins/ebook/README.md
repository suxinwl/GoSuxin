# 电子画册插件 V1.0.0

当前主线保留已编译的画册功能，并提供独立运行插件。支持运行协议的宿主可直接安装预编译 ZIP；安装、更新、卸载及重装不重新编译或重启宿主。后台入口为 `/suxinweb/albums-admin/manage`，中文阅读器为 `/albums/`，英文阅读器为 `/albums-en/`，沿用主程序登录和权限。

## 安装与数据

从 [GitHub Release](https://github.com/suxinwl/GoSuxin/releases/tag/v1.0.0-runtime.20261009) 下载 `ebook-1.0.0-windows-amd64.zip` 或 `ebook-1.0.0-linux-amd64.zip`，在插件市场上传匹配服务器系统和 CPU 的运行包。启动并通过健康检查后生效；失败恢复旧版本。源码 ZIP 用于开发，不作为服务器安装包。

仅初始化 8 张画册表、菜单和 3 个默认分类，不复制旧项目的画册、页面、分享、访问记录、上传文件或云盘密钥。分类、图片/PDF 画册、翻页阅读、私密分享、访问记录、站点设置和存储设置均已迁入。默认本地存储，123 云盘另行配置。

卸载隐藏菜单、关闭接口及阅读入口并停止后台任务，保留数据库、文件、配置及角色授权；重装恢复使用。已安装版本与状态会在宿主重启后恢复。更新会替换画册进程，正在执行的上传、PDF 转换等任务可能中断。

保留现有表前缀和 `storage/albums/`、`storage/config/album-storage.json`、`storage/config/album-site.json`、`storage/album-brand/`；这些业务目录不在发行包中。PDF 转换需要另行安装 Poppler 并确保 `pdftoppm` 可执行；图片画册不需要它。

## 开发与打包

实际服务源码在 `internal/addons/ebook`，独立入口为 `plugins/ebook/cmd`，管理前端在 `web/src/views/album`，阅读器源码在 `plugins/ebook/reader`。主程序保留内置路由，运行包启用后由独立进程接管原接口。

```bash
# 阅读器有修改时先构建
cd plugins/ebook/reader
npm ci
npm run build
cd ../../..
# 构建管理前端和插件运行包
python scripts/build-runtime-plugins.py --os linux --plugin ebook --build-web
```

Release 的对应源码 ZIP 与同一提交的完整 GoSuxin 源码配合开发，包含阅读器源码、资源及插件文件；编译依赖来自完整仓库的共用框架和运行 SDK。完整运行协议、首次宿主升级及依赖说明见 [运行插件指南](../../docs/runtime-plugins.md)。

## 图片拖动排序

2026-09-13 更新：图片管理拖放后立即移动卡片并显示保存状态，确认成功无需重新读取整个列表。图片地址绑定页面 ID，排序不会把同一 URL 变成另一张图片；内容替换使用新的版本标识。旧页码地址仍可访问，文件接口继续按画册及权限核对页面。

保存期间禁止重复拖放与手动刷新。请求异常会重新读取服务器顺序；核对也失败则提示结果待确认，刷新成功后才能再次排序，不自动重发保存请求。已发布画册仍需先确认下架后编辑。更新标准 `ebook-1.0.0-linux-amd64.zip` 即可，主程序无需更新，安装后关闭旧后台标签页重新打开。

## 书架切换与封面预览

`ebook-1.0.0-linux-amd64.zip` 包含此前全部上传/缓存修复。通过代码仓库更新插件，关闭旧阅读页再重新打开即可，无需重建主程序或修改数据库。

公开分类列表在当前页面内缓存一分钟（最多 24 组），返回刚浏览的分类直接显示；过期时保留已有列表并重新查询。首次请求逐页显示，不等待全部分页完成。切换路由取消原页面请求并检查响应所属路由，防止慢响应覆盖当前分类。缓存不包含私密画册详情或分享密码验证；已下架的内容仍由文件接口拒绝读取，公开列表元数据可能延迟最多一分钟更新。

书架、分类封面、阅读器书架抽屉和目录使用最长边 480 像素、JPEG 质量 80 的预览图（保持比例、小图不放大、透明背景合成白色），图片懒加载并异步解码。预览副本与原图缓存共用 512 MiB 上限，最多同时生成两个，原始图片尺寸、内容和正文阅读画质不变。超过 2400 万像素或无法转换的旧图片回退显示原图。首次生成仍需读取原图，重复访问可复用缓存；不会保证冷缓存或慢网络下所有页面瞬间显示。

## 图片缓存与云盘流量

2026-09-12 图片缓存更新：`ebook-1.0.0-linux-amd64.zip`（以及本次生成的标准运行包）通过代码仓库更新即可，包含此前批量暂停/继续、单文件进度和 123 云盘完成校验修复，无需重建主程序或改数据库。

图片、画册封面和分类封面由本站鉴权后返回图片内容，不再每次重定向到临时云盘直链。浏览器使用 `private, no-cache, must-revalidate` 和 ETag 保存副本：每次访问仍向本站校验权限及当前图片，未变化返回 304，不重传图片正文。替换、删除、下架及分享失效继续检查当前数据库记录。后台/分享图片授权地址在同一个半小时窗口内保持稳定，之后续发，授权有效期为 30–60 分钟；插件重启会更新授权签名，需要刷新页面。

云盘图片首次读取时按大小和 MD5 校验后原子写入 `storage/cache/album-images/`，之后由本站磁盘缓存提供，缓存命中不调用云盘下载。缓存最多 512 MiB、4096 个文件，单文件最多 64 MiB；新增缓存时清理闲置七天及最久未使用的副本。同一文件并发请求合并，最多四个同时下载，下载中的临时文件另占少量空间（上限约 256 MiB）。缓存目录位于非公开存储，随插件升级/重启保留，不进入发行包，也不作为业务数据备份；缓存缺失会重新从云盘读取。

这会减少反复消耗 123 云盘 CDN 流量，但由部署服务器承担浏览器缓存未命中时的图片传输与缓存磁盘开销。跨设备首次访问、浏览器主动清缓存、缓存淘汰后仍可能传输图片；不承诺零流量。不要为此开启整个站点/API 的 Nginx 公共代理缓存。缓存写入或完整性校验失败返回错误，不偷偷回退到重复跳转下载。

HTTP 缓存语义参考：[RFC 9111](https://www.rfc-editor.org/rfc/rfc9111.html#section-5.2.2.4)。

## 批量图片上传

画册管理中的“上传图片”和图片管理中的“批量上传”均逐张检查服务器保存结果，并显示文件名、成功、失败、结果待确认及未发送数量。明确的单张业务失败后继续处理后续图片；批次结束或暂停时统一刷新图片列表或页数，上传期间暂停加载预览，结束后按需加载。列表刷新失败单独提示，不会把已保存文件算成上传失败。

每张图片显示独立上传进度条、百分比、文件大小与已传输大小，依次经历“等待上传 → 正在上传 → 等待服务器保存 → 已保存”。字节进度来自浏览器上传事件，不代表云盘保存进度；上传 100% 后等待服务器返回才确认成功。浏览器未提供可计算进度时显示“等待进度”，不模拟百分比；失败或结果待确认时保留最后进度。上方总进度按已处理文件数量计算。

网络断线或响应异常可能发生在文件保存之后，此类文件标为“结果待确认”，不自动重传，并暂停后续队列。连接恢复后可点击“继续未上传文件”，仅发送未发送项；登录或权限拒绝也会暂停。可手动“暂停后续上传”，当前文件完成后暂停，未发送文件只保留在当前页面，关闭页面需要重新选择。请先刷新图片列表核对，再只选择确定缺失的文件补传。上传期间请保持页面打开；后补上传的页面排在末尾，可在图片管理中调整顺序。

当前标准运行包：`ebook-1.0.0-linux-amd64.zip` 包含请求数量优化、暂停/继续及此前 123 云盘校验修复，只需通过代码仓库更新插件。已经显示单文件实时进度的后台不必再次更新主程序前端。



## 站点品牌与路径

在 **画册中心 → 站点设置** 分别修改中英文 Logo、品牌名称、浏览器标题、首页标题、介绍、版权及官网链接。默认官网链接为空，留空隐藏官网入口；公开阅读器没有固定的 Suxin 官网链接。默认路径 `/albums/` 与 `/albums-en/` 自动使用部署域名。

路径可改为同域名下 `/catalogue/`、`/en/catalogue/`，或分别填写完整的 HTTP(S) 地址。不同域名必须先配置 DNS、HTTPS 和到主程序的反向代理，保留 Host。地址不能占用后台/API/静态资源目录。保存后刷新页面即可生效，不需要重新构建；旧地址重定向由部署方按需配置。Logo 同时用作画册浏览器图标；上传支持 PNG/JPG/WEBP，最大 5 MB。
